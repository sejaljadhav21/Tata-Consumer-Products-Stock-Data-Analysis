# 📊 Tata Consumer Products Stock Data Analysis Dashboard

## Overview

This project demonstrates an end-to-end stock market data analysis workflow focused on price movement trends, trading volume behavior, and volatility patterns.  

The dashboard analyzes 52-week high/low performance, open vs close price behavior, monthly trading volume trends, and daily price range fluctuations across different time dimensions.

The objective is to enable faster market trend identification and performance evaluation through an interactive, KPI-driven reporting layer.

The solution was built entirely using Microsoft Excel, with emphasis on structured data preparation, accurate aggregations, and clean dashboard design.

- Executive-level KPI summary cards

## Key Insights & Capabilities

- Built a fully interactive stock analysis dashboard in Excel, transforming raw historical trading data into structured, analysis-ready datasets.  

- Designed dynamic KPI cards to monitor:
  - Maximum 52-week high  
  - Minimum 52-week low  
  - Average open price  
  - Maximum close price  
  - Average trading volume  

- Performed time-series analysis to identify:
  - Monthly trading volume fluctuations  
  - Seasonal price movement trends  
  - Quarter-wise high vs low comparisons  
  - Weekday-based price behavior  

- Implemented pivot-driven visualizations and slicers to enable dynamic filtering and multi-dimensional exploration.

- Consolidated multiple analytical views into a single reporting interface to improve clarity and decision-making efficiency.
